# 工事発注アプリ V7（試験運用版）

不動産管理業務向けの工事発注Webアプリです。

## 主な機能
- 物件・号室・入居者名・連絡先の入力
- 不具合ジャンル／設備の選択
- 不具合内容の音声入力補助
- 複数写真の添付・圧縮
- 物件 × 不具合ジャンルに応じたおすすめ業者の自動選択
- 発注先業者の手動変更
- 業者への指示文プリセット
- 発注履歴
- iPhoneの共有機能を使った送信

## GitHub Pagesでの公開
このリポジトリのルートに `index.html` を置いています。
GitHubの Settings → Pages から公開元を設定すると、Safariからアクセスできます。

## 注意
試験運用版です。入居者名・電話番号などの個人情報をソースコードへ直接書き込まないでください。
